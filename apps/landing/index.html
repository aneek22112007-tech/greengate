03 · How it works

Carbon becomes a trait.
Flagsmith makes the call.

  1. 1

    Request

    A reader opens an article. A stable id comes from the gg_uid cookie or x-gg-uid header.

  2. 2

    Read the grid

    Electricity Maps carbon-intensity-level/latest returns low, moderate or high for the zone. Cached 15 min, stale up to 6 h.

  3. 3

    Send traits

    carbon_level and grid_zone go to Flagsmith as identity traits. No hard overrides.

  4. 4

    Segments decide

    Self-hosted Flagsmith segments map the level to a variant of the multivariate flag heavy_feature_mode.

  5. 5

    Feature adapts

    full live summary and motion. eco cached summary, still image. off paused, with a plain explanation.

Kill switch

greengate_enabled off forces full when the product must stay on.

Flagsmith down?

The plugin falls back to the local mapping and marks source: local. It recovers by itself.

No token?

Without an Electricity Maps token the level is simulated, and the response says so.

05 · Plugin

One call in your app.
@greengate/flagsmith

import { Flagsmith } from '@flagsmith/nodejs';
import { createGreenGate } from '@greengate/flagsmith';

const gate = createGreenGate({
  flagsmith: new Flagsmith({ environmentKey: process.env.FLAGSMITH_ENVIRONMENT_KEY! }),
  electricityMapsToken: process.env.ELECTRICITY_MAPS_TOKEN,
  mapping: 'strict',   // low→full, moderate→eco, high→off
  mode: 'traits',      // Flagsmith segments choose
});

const decision = await gate.evaluate('user-42');
// decision.variant → 'full' | 'eco' | 'off'
import express from 'express';
import { greengateMiddleware } from '@greengate/flagsmith';

const app = express();
app.use(greengateMiddleware(gate));   // attaches req.greengate

app.get('/article/:slug', (req, res) => {
  const { variant, carbonLevel, source } = req.greengate;
  if (variant === 'off') return res.json({ summary: null });
  // full → live summary, eco → cached summary
});
